# INSTALL - ChatGPT Export v6.0.0

## Quick install

1. Download or clone the repository.
2. Open `brave://extensions/` or `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the folder containing `manifest.json`.
6. Reload ChatGPT.

## Runtime files

```text
manifest.json
background.js
content-export.js
export-style.css
icons/
```
