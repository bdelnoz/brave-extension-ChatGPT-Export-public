# INSTALL - ChatGPT Export v6.0.0

## Get the extension

Choose one of these methods:

### Option A - Download the release ZIP

Download the latest official ZIP from the repository's **Releases** section, then extract it.

### Option B - Clone the repository

```bash
git clone https://github.com/bdelnoz/brave-extension-ChatGPT-Export-public.git
```

### Option C - Fork the repository

You may use GitHub's **Fork** function when you want to inspect the code or prepare a contribution for review. Forking does not change the rights granted by `LICENSE` and does not make a fork an official release.

## Brave

1. Open `brave://extensions/`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the extracted or cloned directory containing `manifest.json`.
5. Reload ChatGPT.

## Chrome / Chromium

Open `chrome://extensions/` and use the same **Load unpacked** procedure.

## Runtime files

```text
manifest.json
background.js
content-export.js
export-style.css
icons/
```
