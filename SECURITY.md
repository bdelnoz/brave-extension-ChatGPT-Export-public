# SECURITY - ChatGPT Export v6.0.0

ChatGPT Export is a local browser extension.

- No analytics SDK.
- No telemetry endpoint.
- No separate NoXoZ.be export backend.
- File bundling can access eligible ChatGPT/OpenAI-hosted resources associated with the active session.
- Generic ChatGPT HTML viewer pages are rejected when a real non-HTML file is expected.

Exports may contain confidential conversation data. Protect generated ZIP files accordingly.

ChatGPT Export is an independent project and is not affiliated with, endorsed by, sponsored by, or developed by [OpenAI](https://openai.com/).
